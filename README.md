# Круги на Соколе

Браузерный 3D-кликер: бегаешь круги по стадиону «Сокол», получаешь премию, растёшь от специалиста до министра спорта.
Внутренняя шутка, некоммерческий проект.

Это собранная версия игры для GitHub Pages: один `index.html` (Three.js встроен), картинки, модели героя и людей на стадионе, service worker.
Прогресс хранится в браузере игрока (localStorage).

Сторонние библиотеки и модели — в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
